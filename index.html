01 / How I learn

배우는 과정에서도 방법을 찾습니다.

지금까지의 학습 경험에서 반복해서 나타난 세 가지 방식을 하나의 흐름으로 정리했습니다.

01 / Learn

적극적으로 질문하고 보완합니다.

새로운 분야를 배우면서 막히는 부분을 그냥 넘어가지 않습니다. 강사에게 질문하고 AI를 활용해 부족한 부분을 추가로 학습하며, 배운 내용을 실제 과제 수행으로 연결합니다.

02 / Verify

제대로 이해했는지 확인합니다.

단순히 설명을 듣고 넘어가기보다 다른 비유와 방식으로 다시 설명해 달라고 요청하며, 내가 개념을 제대로 이해했는지 스스로 교차검증합니다.

03 / Improve

문제의 원인을 기록합니다.

오류를 해결하는 것에서 끝내지 않고 발생 원인을 분석하고 메모합니다. 이를 통해 비슷한 문제의 반복을 줄이고, 경험을 다른 사람에게 설명할 수 있는 지식으로 연결합니다.

02 / What I did

말보다 과정으로 보여드립니다.

실제 경험에서 무엇을 마주했고, 어떤 행동을 했으며, 그 결과 무엇이 달라졌는지를 중심으로 정리했습니다.

01
Where
학원 / 네트워크 학습

모르는 부분을 그냥 넘기지 않는 학습

When / Where

Action

수업을 따라가면서 막히는 부분이 생기면 강사님에게 질문하고, AI를 활용해 부족한 부분을 추가로 학습했습니다.

Result

배운 내용을 이해하고 과제를 성공적으로 수행할 수 있었습니다.

02
Where
학원 / 새로운 내용 학습

이해한 내용을 다른 관점에서 검증하기

When / Where

학원에서 새로운 내용을 학습하면서 개념을 이해하고 다음 단계로 넘어가야 했습니다.

Action

배운 내용을 AI에게 비슷한 비유나 다른 방식으로 설명해 달라고 요청하고, 내가 제대로 이해하고 있는지 교차검증했습니다.

Result

처음에는 애매하게 이해했던 내용도 개념 간의 흐름을 확실하게 잡고 다음 단계로 넘어갈 수 있었습니다.

03
Where

오류를 해결하는 것에서 원인을 기록하는 것으로

When / Where

프로그래밍을 공부하면서 오류가 발생하거나 학습이 막히는 상황을 경험했습니다.

Action

단순히 오류를 해결하는 데서 끝내지 않고, 왜 해당 오류가 발생했는지 원인을 분석하고 그 내용을 메모해두었습니다.

Result

비슷한 오류가 다시 발생하는 비중이 크게 줄었고, 비슷한 문제를 겪는 주변 사람들에게 원인과 해결 방향을 조언할 수 있게 되었습니다.
